# Feature Ideas

This folder is for capturing possible JobHub features before deciding whether they belong in scope.

Each idea should answer two separate questions:

1. Would this be useful to a job seeker?
2. Is this feasible and appropriate for the current product stage?

Do not treat an idea stored here as an approved requirement. Move an idea into the analysis or strategy work only after it has been reviewed.

## Suggested workflow

```text
Capture the idea
    ↓
Describe the user problem
    ↓
Check evidence and assumptions
    ↓
Assess feasibility, risks and dependencies
    ↓
Decide: explore, prototype, defer or reject
```

## Feasibility dimensions

- User value
- Evidence supporting the problem
- Technical complexity
- Data or source availability
- AI reliability requirements
- Privacy and security implications
- Operational and maintenance cost
- Fit with the current JobHub scope

Use `feature-idea-template.md` for new ideas.
