# Experiment Templates

Every run should include, where applicable:

- `README.md` — question, scope, model and run metadata.
- `fixtures/` — synthetic or redacted inputs.
- `prompts/` — exact prompts used.
- `code/` — runner scripts.
- `raw-output/` — untouched model responses.
- `reviewed-output/` — human-reviewed results.
- `claim-ledger.md` — claim-to-source audit.
- `findings.md` — observed results.
- `limitations.md` — unresolved uncertainty and non-conclusions.
