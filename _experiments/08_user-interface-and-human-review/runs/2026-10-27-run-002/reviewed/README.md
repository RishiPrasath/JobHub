# Reviewed Correction Records

These files preserve human corrections without modifying the raw model outputs.

- `R4-JB-003-corrections.json`
- `R4-JB-006-corrections.json`
- `R4-JB-011-corrections.json`

The records distinguish accepted corrections, rejected claims, coverage overrides and human decisions. They are not evidence that the model output was correct; they are the review layer required before any output becomes a trusted record.
