```markdown
Status: proposed | accepted | superseded by NNNN
Date: YYYY-MM-DD
Decided by: owner

## Context
## Options considered
## Decision
## Evidence (finding IDs)
## Consequences
```

Earlier product decisions are in [strategy/08_decision-log.md](../../strategy/08_decision-log.md). [proposed/](proposed/README.md) holds research-direction proposals that were never accepted.
