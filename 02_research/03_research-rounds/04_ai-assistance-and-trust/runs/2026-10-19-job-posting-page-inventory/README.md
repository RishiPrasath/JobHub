# Round 04 run — job-posting page inventory

Status: bounded live inventory complete for this pass

Access date: 2026-10-19 (Singapore time)

## Purpose

This run tests how job boards and recruitment sites present vacancy information across page types. It supports Round 04 Objective 5: creating a research-backed vocabulary for reading postings without assuming that any board, employer or industry uses one universal schema.

## What was inspected

- 20 Chrome/AgentHub page observations across expanded source ecosystems;
- job-search results, job-detail, public-service landing, employer-support and recruitment pages;
- office/professional, frontline/shift, logistics/trade, technical and public-service examples;
- visible page content only, with dynamic, missing and inaccessible content recorded as limitations.

This is a page inventory, not a prevalence study, vacancy-authenticity verdict, or product-scope decision. Several pages are platform or support pages rather than individual vacancies.

## Bottom line

The sample supports a common *reading model*—identity, location/arrangement, compensation, role, requirements, process and platform context—but not a claim that every board contains every section. Detail pages differ materially in structured fields, free-text depth, application route, dates, employer/intermediary identity and platform-generated signals. A useful JobHub research model should preserve raw labels and source ownership, show unknowns explicitly, and compare search-card data with detail-page data.
