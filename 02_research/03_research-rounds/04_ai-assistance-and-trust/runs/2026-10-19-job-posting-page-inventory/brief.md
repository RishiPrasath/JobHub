# Run brief

## Research question

What page types, sections and fields appear across Singapore-facing job boards and recruitment sites, and how should the observed information be recorded without silently inferring employer intent or missing details?

## Objectives

1. Inventory visible content sections on search, detail, employer/public-service and support pages.
2. Compare common concepts under different labels.
3. Separate employer-, agency-, government- and platform-authored content.
4. Record missing, vague, conditional, contradictory and inaccessible fields.
5. Identify page-level implications for a future evidence model while leaving product scope and technical stack undecided.

## Method

- Live reading in the shared Chrome session.
- Direct page URLs, not search snippets, used as page evidence.
- One record per inspected page, retaining the final URL and page type.
- Short faithful observations only; no full-page copying.
- Platform help pages retained as lifecycle evidence, not counted as vacancy detail pages.
- Access outcomes preserved when a page was partial or dynamic.

## Source boundaries

- Singapore-first and public web.
- The initial Chrome sample covered six source ecosystems: Indeed Singapore, MyCareersFuture, FastJobs, Careers@Gov, Jobstreet Singapore and LinkedIn. AgentHub and Chrome fallback checks then expanded the observation set to additional general, specialist, agency, public-sector and employer-hosted sources.
- No login, CAPTCHA bypass, application submission, external contact, personal-document upload or private data collection.
- No claim that a listing is fake, ghost, active or closed unless the page explicitly states that status.

## Classification rules

Each page receives:

- page type;
- geography;
- vacancy versus general-career/support context;
- visible section list;
- field ownership where practical;
- field state: present, partial/vague, conditional, contradictory, not present, not visible, blocked, not applicable or unknown;
- access and rendering notes.

“Not present” means the field was not found during this inspection. “Not visible” means the page could not be inspected sufficiently. These are not interchangeable.

## Bounded stopping rule

This pass stops when multiple board ecosystems and page types have been compared, the same core field groups have been tested against materially different examples, and remaining uncertainty is caused by changing or inaccessible public pages rather than by a missing basic comparison. A later round should expand the balanced sample before using prevalence language.

## Specialist handoffs

- Taxonomy: define page ecosystem, canonical field groups and ownership/state vocabulary.
- Sampling: recommend additional comparable pages and page-type variants.
- Evidence review: define auditable page records, contradiction controls, dynamic-content checks and stopping criteria.

Specialists did not edit the run files. The coordinator reconciled their recommendations with the Chrome observations.
