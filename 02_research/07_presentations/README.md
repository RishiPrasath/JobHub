# Research presentations

Readable briefings of completed research, kept separate from evidence and product decisions.

Start with [The work behind getting a job](01_job-seeker-research-story/README.md), the current storytelling briefing. It covers the domain through job-seeker decisions, with source notes, a readable-text mode and an editable export. No Microsoft Office, account, upload or installation is needed for browser reading.

The [earlier research findings briefing](00_research-findings/README.md) remains preserved as a historical version.

## Structure

Each numbered briefing contains its reading deck, editable export, sources and rebuilding instructions. Preserve uncertainty and link back to the research rather than treating slides as a new source of evidence. Never publish private resumes or internal workspace contents in a presentation.

## Free and open alternatives

Checked against official project pages on 2026-10-18:

| Option | Suitable use | Considerations |
| --- | --- | --- |
| [LibreOffice Impress](https://www.libreoffice.org/) | Free, open-source desktop presentation editing | Requires installation. Check imported PPTX layout in Impress before presenting. |
| [Marp](https://marp.app/) | Agent-authored Markdown slides, exported to HTML, PDF or PowerPoint | MIT-licensed tools. Conversion requires its tooling. Export formats have different editing characteristics. |
| [reveal.js](https://revealjs.com/) | Open-source browser presentations | Supports a locally hosted/offline setup, but needs framework assets and more HTML setup. |
| Standalone HTML | Immediate offline reading in an existing browser | Used for this first briefing. Custom HTML/CSS/JavaScript, without a framework or external runtime requests. |

The current briefing also includes an editable PPTX and Marp-compatible Markdown. Neither LibreOffice nor Marp was installed for this task. These choices concern presentation delivery only, not JobHub's product stack.

## Agent-assisted workflow

Use the existing Evidence Synthesizer to draft an evidence-linked outline. Let a presentation author turn it into slides, then request an independent evidence and UX readability review before delivery. These are bounded assignments, not additional product decision makers. Research query planning remains with the existing query specialist when new evidence is necessary.

For the current briefing, three specialists audited the baseline, later public/internal evidence, and story/audience requirements while the coordinator authored the deck. Independent evidence and visual reviews informed revisions. Use the [dedicated presentation role](../../_agents/18_research-presentation-strategist.md) for future work. Final acceptance remains with the owner.
