# Research Results

This folder contains reviewed synthesis, not raw browsing notes or unverified agent output.

Every result should link to the research runs and evidence supporting it. It should distinguish facts, source claims, interpretations, hypotheses, unknowns, contradictions, confidence, and product implications.

The thematic folders are:

- `product-and-users/`
- `ai-and-job-hunting/`
- `market-and-competition/`
- `ux-and-product-surface/`
- `development-and-technology/`

`00_cross-research-synthesis.md` should be updated only when multiple research areas need to be reconciled.
