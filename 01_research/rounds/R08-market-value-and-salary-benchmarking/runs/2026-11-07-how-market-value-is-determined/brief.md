# Run brief — How market value is determined

Date: 2026-11-07 (Singapore). Round: [08](../../round-brief.md).

## Questions

1. How are salary benchmarks produced (surveys, posted salaries, self-reports)? How are the numbers cleaned, matched to jobs and summarised (percentiles, aging, geography)?
2. Which variables determine pay, and how strong is the evidence for each (education, experience, skills, role level, industry, company size, location, demand and supply)?
3. How do skills turn into pay? What is known about skill premiums, and what is only correlation?
4. What does the Singapore context add (official wage data, salary guides, total compensation, rules)?
5. How do employers set an offer (bands, midpoints, percentiles, budget), and how should a job seeker triangulate a range?
6. Where does salary data go wrong (bias, staleness, sample size) and how should uncertainty be shown?

## Method

Six workstreams, one per question, each done by a separate Haiku-model research agent using web search and page reading only. Each returns a sourced note: numbered claims with a source URL and a label (primary source / secondary source / practice or opinion), the points on which sources disagree, and gaps. Raw notes are kept unedited in `evidence/`. The lead researcher then opens primary sources for the claims the report depends on, records which were confirmed, and writes `findings.md`.

## Source rules

Prefer government statistics and methodology documents, academic and professional-body publications, and survey-provider method notes over blogs and vendor marketing. Vendor claims about their own accuracy are recorded as claims. Anything an agent states from memory is labelled as such and not used as evidence.

## Output

`findings.md` (the report), `limitations.md`, `sources.md`, `evidence/` (raw agent notes).
