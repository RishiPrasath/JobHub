## Assignment rule

Use the narrowest team that can answer the question well. Do not ask every agent to research every topic. The primary agent owns the question; support agents contribute a defined angle; the Evidence Synthesizer checks provenance; and the appropriate specialist reviews risk before a result is promoted.
