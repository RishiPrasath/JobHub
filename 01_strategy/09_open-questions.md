# Open Questions

## Product

- Which job-seeker problem should JobHub solve first?
- Which user segment has the strongest unmet need and is reachable for research?
- Is the primary value job intelligence, application preparation, career support, or a combined workspace?
- What outcome should define success beyond application volume?

## Product surface

- Where do users discover jobs, and where do they perform serious preparation?
- Which actions need to work on a phone immediately?
- Which actions benefit from a larger screen?
- Should the first product be responsive web, mobile-first, native, browser-assisted, or another shape?

## AI and trust

- Which tasks should be automated, assisted, or kept entirely under user control?
- What evidence must be shown before users trust analysis or company warnings?
- How should fit analysis avoid deterministic or discriminatory judgments?
- How should authenticity and user authorship be preserved?

## Development

- Where do Gherkin and Cucumber provide enough value to justify maintenance?
- What is the right balance between exploration, specifications, tests, and prototypes?
- How should Codex subagents be coordinated and evaluated?
- What technical skills should the product owner learn directly?

## Evidence

- Which claims from external AI-SDLC sources apply to JobHub?
- What relevant evidence exists in the internal Job Hunt workspace?
- Which questions are better answered by research, a prototype, or a user test?
