# Strategy Evidence

This folder will contain evidence used to support strategy decisions.

Suggested organization:

```text
evidence/
├── external/   # Web research, papers, standards, market sources
└── internal/   # Findings from the internal Job Hunt workspace
```

Each evidence record should identify its source, date, question, relevant observation, limitations, and the strategy decision it informs. Evidence should not be treated as a product requirement until it has been interpreted and recorded in the appropriate strategy document.
